# FinanCerto - Mobile Development Rules (React Native)

## 1. Tech Stack & Environment
- **Framework:** React Native (Functional Components com Hooks).
- **Styling:** StyleSheet nativo ou Styled Components (conforme padrão atual).
- **Navigation:** React Navigation (Stack ou Tabs).
- **Icons:** Expo Icons ou React Native Vector Icons.

## 2. UI & UX Guidelines
- **Plataformas:** Sempre garanta compatibilidade entre iOS e Android.
- **Safe Area:** Utilize `SafeAreaView` para evitar que o conteúdo fique sob notches ou barras de status.
- **Feedback Visual:** Use `TouchableOpacity` ou `Pressable` para interações de clique, garantindo feedback visual imediato.
- **Loading States:** Implemente `ActivityIndicator` ou Skeletons durante chamadas à API do FinanCertoBack.

## 3. Padrões de Código
- **Arquitetura:** - `/components`: Componentes reutilizáveis (botões, inputs de moeda).
  - `/screens`: Telas completas da aplicação.
  - `/services`: Chamadas de API (utilizando Axios para conectar com o `finanCertoBack`).
  - `/hooks`: Lógica de estado personalizada.
- **Hooks:** Prefira o uso de `useCallback` e `useMemo` em listas longas (como histórico de transações) para performance.
- **Async Storage:** Utilize para persistir o token JWT localmente de forma segura.

## 4. Integração com o Back-end
- **Conexão:** O app mobile consome exclusivamente a API REST em `/back-end/finanCertoBack`.
- **DIP (Dependency Inversion):** Centralize a configuração da base URL da API em um único arquivo de serviço para facilitar a troca entre localhost (via IP da máquina) e ambiente de produção.
- **Tratamento de Erros:** Exiba alertas amigáveis (em Português) caso a API esteja offline ou o token JWT expire.

## 5. Mobile Specifics (Importante)
- **Keyboard:** Sempre utilize `KeyboardAvoidingView` em telas de formulário (Login, Cadastro de Transação).
- **Inputs:** Para campos financeiros, use `keyboardType="numeric"` ou `"decimal-pad"`.
