# FinanCerto - Regras Globais de Contexto (IA)

## 1. Visão Geral do Sistema
O FinanCerto é um ecossistema financeiro dividido em micro-serviços dentro deste monorepo:
- **/back-end/finanCertoBack**: Core do sistema, gestão de usuários e transações (Spring Boot).
- **/back-end/financerto-analytics**: Parte de relatorios e futuras implementacao de analises de dados (FastAPI).
- **/front-end-web**: Interface administrativa e do usuário (React).
- **/front-end-mobile**: Interface administrativa e do usuário (React Native).

## 2. Comunicação Inter-Serviços
- O Backend Java é a "Fonte da Verdade".
- O serviço de Analytics consome dados via chamadas REST ou integração direta de banco conforme definido.
- O Frontend consome a API do Backend Java usando o padrão RESTful.

## 3. Padrões de Desenvolvimento Gerais
- **Idioma:** Código e documentação técnica devem ser em Inglês. Mensagens de erro para o usuário final em Português.
- **Segurança:** O fluxo de autenticação é centralizado no Spring Security com JWT. Nunca sugira métodos de autenticação básica sem tokens.
- **Docker:** O projeto utiliza Docker Compose para orquestração local. Sempre considere a compatibilidade com containers ao sugerir novas dependências.

## 4. Prioridade de Contexto
Ao gerar código:
1. Se o arquivo estiver em `/back-end/finanCertoBack`, siga os padrões de Java 21 e Spring Boot 3.
2. Se estiver em `/back-end/financerto-analytics`, utilize Python 3.10+ e FastAPI.
3. Se estiver em `/front-end-web`, use React funcional com Hooks.
4. Se estiver em `/front-end-mobile`, use React Native com Hooks.
