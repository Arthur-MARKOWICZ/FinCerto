# FinanCerto - Back-end Development Rules (Spring Boot)

## 1. Tech Stack & Core
- **Language:** Java 21 (LTS).
- **Framework:** Spring Boot 3.x.
- **Persistence:** Spring Data JPA / Hibernate.
- **Database:** MySQL (Configurado via Docker Compose).
- **Security:** Spring Security + JWT (Stateless).
- **Validation:** Jakarta Bean Validation (Hibernate Validator).

## 2. Padrões de Arquitetura (Camadas)
- **Controller:** Apenas mapeamento de endpoints e chamadas ao Service. Use `@RestController`.
- **Service:** Onde reside 100% da lógica de negócio. Use `@Service`.
- **Repository:** Interfaces estendendo `JpaRepository`. Use Queries Derivadas sempre que possível.
- **DTO (Data Transfer Object):** Utilize **Java Records** para todas as entradas (Requests) e saídas (Responses). Nunca exponha Entidades JPA nos Controllers.

## 3. Uso do Lombok & Jakarta
- **Boilerplate:** Use `@Data`, `@NoArgsConstructor` e `@AllArgsConstructor` em Entidades.
- **Injeção de Dependência:** Use `@RequiredArgsConstructor` sobre a classe e declare os atributos como `private final`. Evite `@Autowired` em atributos.
- **Persistence:** Use as anotações do `jakarta.persistence.*` (como `@Entity`, `@Id`, `@GeneratedValue`).

## 4. Segurança e JWT
- **Filtros:** Toda requisição deve passar pelo `JwtAuthenticationFilter`, menos a de cadastro e login de usuários.
- **Contexto:** Use o `SecurityContextHolder` para obter o usuário logado em vez de passar IDs manualmente no corpo da requisição quando for sensível.
- **Senhas:** Utilize `BCryptPasswordEncoder` para hashing.

## 5. Tratamento de Erros e Logs
- **Global Handler:** Utilize `@ControllerAdvice` com `@ExceptionHandler` para retornar respostas padronizadas (JSON com timestamp, status e mensagem).
- **Tratamento Manual:** Nunca use `System.out.println`. Utilize SLF4J (Lombok `@Slf4j`) para logs de erro e rastreamento.

## 6. Diretrizes de Código
- **Nomenclatura:** Classes, métodos e variáveis em **Inglês**.
- **Mapeamento:** Use `@Mapping` (MapStruct) ou construtores manuais para converter Entidades <-> DTOs.
- **Transactions:** Use `@Transactional` apenas em métodos de escrita (Create, Update, Delete) no Service.
