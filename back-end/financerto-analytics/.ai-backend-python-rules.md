# FinanCerto - Analytics Service Rules (FastAPI / Python)

## 1. Tech Stack & Environment
- **Language:** Python 3.10+.
- **Framework:** FastAPI.
- **Data Manipulation:** Pandas, NumPy.
- **Database Access:** SQLAlchemy (Assíncrono).
- **Validation:** Pydantic v2 (para Schemas de entrada e saída).

## 2. Integração com Banco de Dados (Shared Database)
- **Modo de Operação:** Este serviço opera primordialmente em **READ-ONLY**. 
- **Sincronia com Java:** As tabelas são gerenciadas pelo Spring Boot (JPA). Nunca sugira migrações (Alembic) que alterem a estrutura das tabelas existentes.
- **Mapeamento:** Certifique-se de que os modelos SQLAlchemy reflitam exatamente os nomes de colunas e tabelas definidos no `finanCertoBack`.

## 3. Padrões de API (FastAPI)
- **Endpoints:** Utilize `APIRouter` para organizar as rotas por domínio (ex: `/reports`, `/predictions`).
- **Async/Await:** Sempre utilize funções `async def` para rotas de I/O de banco de dados para garantir alta performance.
- **Dependency Injection:** Use o sistema de `Depends()` do FastAPI para gerenciar sessões de banco de dados.

## 4. Lógica de Analytics
- **Pandas Integration:** Converta resultados de queries do banco diretamente para DataFrames do Pandas para cálculos complexos (médias, projeções, agrupamentos).
- **JSON Response:** Garanta que os cálculos retornem tipos primitivos compatíveis com JSON (use `.item()` no NumPy se necessário).

## 5. Diretrizes de Código Python
- **Style Guide:** Siga rigorosamente o **PEP 8**.
- **Typing:** Utilize Type Hints em todas as funções e parâmetros.
- **Docstrings:** Documente funções complexas de cálculo usando o formato Google ou NumPy.
- **Nomenclatura:** snake_case para funções/variáveis e PascalCase para classes.

## 6. Segurança
- **JWT:** Valide o token JWT no cabeçalho das requisições para garantir que apenas usuários autenticados acessem os relatórios. (O segredo do JWT deve ser o mesmo do serviço Java).
