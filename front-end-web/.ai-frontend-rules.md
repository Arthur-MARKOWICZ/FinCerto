# FinanCerto - Web Development Rules (React)

## 1. Tech Stack & Core
- **Framework:** React (Functional Components).
- **Hooks:** Uso extensivo de `useState`, `useEffect`, e Hooks customizados para lógica de API.
- **Styling:** Tailwind CSS (Priorize classes utilitárias para rapidez e responsividade).
- **Icons:** Lucide React ou FontAwesome.
- **State Management:** Context API para autenticação e estados globais simples.

## 2. Arquitetura de Pastas
- `/src/components`: Componentes de UI atômicos (Buttons, Cards, Modals).
- `/src/pages`: Componentes de rota (Dashboard, Login, Transactions).
- `/src/services`: Configuração do Axios e chamadas para o `finanCertoBack`.
- `/src/assets`: Imagens, SVGs e estilos globais.
- `/src/hooks`: Lógica reutilizável (ex: `useAuth`, `useTransactions`).

## 3. Padrões de Interface (UI/UX)
- **Responsividade:** Design "Mobile-first" usando breakpoints do Tailwind (`md:`, `lg:`).
- **Formulários:** Utilize `react-hook-form` para validações.
- **Feedback de Carregamento:** Implemente Spinners ou Skeleton screens durante requisições assíncronas.
- **Tabelas/Listas:** Formate valores monetários sempre em Reais (BRL) usando `Intl.NumberFormat`.

## 4. Integração com Back-end (Spring Boot)
- **Axios:** Configure uma instância base com o `baseURL` apontando para o `/back-end/finanCertoBack`.
- **Interceptors:** Utilize interceptors para anexar o Token JWT automaticamente no cabeçalho `Authorization: Bearer <token>`.
- **Tratamento de Erros:** Capture erros 401 (Não autorizado) para redirecionar o usuário ao login caso o token expire.

## 5. Diretrizes de Código
- **Props:** Use desestruturação de props nos componentes.
- **Clean Code:** Componentes não devem exceder 250 linhas; se excederem, extraia lógica para sub-componentes ou Hooks.
- **Nomenclatura:** PascalCase para componentes e camelCase para funções/variáveis.
